# 0005. 연결 토큰을 해시에 저장해 같은 서버 재연결을 저장소 수준에서 구분

상태: 채택 (ADR-0006에 흡수)
날짜: 2026-09-30
출처: ADR-0004 규칙 3

## 문제

같은 서버로 재연결하면 새 연결도 `server_id`가 같아서 저장소만 봐서는 옛 연결과 새 연결을 구분할 수 없다.
현재는 로컬 맵의 emitter 인스턴스 동일성(`remove(key, value)`)으로 해결한다. 서버 재시작 후 옛 기록이 남는 경우 등에는 이 방법이 닿지 않는다.

## 제안

연결마다 토큰(UUID)을 만들어 해시에 `conn_token` 필드로 저장하고, unregister.lua가 `server_id`와 토큰을 함께 비교한다.

## 채택 조건

로컬 인스턴스 비교로 잡히지 않는 경합이 실험에서 관찰될 때.

## 결정 기록

- 2026-09-30 대기. PRD 11절에서 이관.
- 2026-10-01 ADR-0006의 연결 epoch이 토큰 역할을 겸한다. 삭제 조건이 epoch 일치로 바뀌어 같은 서버 재연결도 저장소에서 구분된다.
