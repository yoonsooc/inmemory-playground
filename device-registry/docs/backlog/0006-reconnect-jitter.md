# 0006. 재연결 지연 지터

상태: 대기
날짜: 2026-09-30
출처: PRD 10절 알려진 한계

## 문제

서버 한 대를 재배포하면 그 서버의 연결이 동시에 끊겨 모든 기기가 같은 백오프 시각에 한꺼번에 재연결한다. 기기 수가 많으면 재연결 폭주가 된다.

## 제안

시뮬레이터의 백오프에 무작위 지연을 더한다 (예: 백오프 × 0.5~1.5).

## 채택 조건

실험 규모(기기 수십 대)에서는 문제가 되지 않는다. README 한계에 적는 것으로 충분하다.
