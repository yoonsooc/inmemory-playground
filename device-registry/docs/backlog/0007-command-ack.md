# 0007. 명령 전달 확인(ack)

상태: 대기
날짜: 2026-09-30
출처: ADR-0005

## 문제

명령 POST는 "Pub/Sub에 발행했다"까지만 보장한다. 연결 주인 서버가 SSE로 썼는지, 기기가 받았는지는 응답에 담기지 않는다. Pub/Sub 자체도 구독자가 없으면 메시지를 버린다.

## 제안

기기가 명령을 받으면 HTTP로 ack를 보내고, 명령 id별 상태를 Valkey에 기록한다. 또는 Pub/Sub 대신 Stream을 써서 소비 확인을 남긴다.

## 채택 조건

비목표(PRD 3절: 명령 전달 보장)를 바꾸기로 할 때만.
