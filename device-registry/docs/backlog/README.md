# Backlog

완성 기준(PRD 9절) 밖의 항목을 하나씩 문서로 쌓는다. 문서는 지우지 않고 상태만 바꾼다.

상태: 대기 → 채택 (구현했거나 ADR로 승격) | 폐기 (이유를 남긴다)

| 번호 | 제목 | 상태 | 출처 | 날짜 |
|---|---|---|---|---|
| [0001](0001-renew-also-sadd.md) | 갱신(renew)에서도 `devices:known`에 SADD | 대기 | 이중 쓰기 리뷰 | 2026-09-30 |
| [0002](0002-unregister-retry-queue.md) | 삭제 실패 시 로컬 대기 목록으로 재시도 | 대기 | 이중 쓰기 리뷰 | 2026-09-30 |
| [0003](0003-dual-write-failure-metrics.md) | 등록·갱신·삭제 실패 카운터 (Micrometer) | 대기 | 이중 쓰기 리뷰 | 2026-09-30 |
| [0004](0004-client-side-liveness-heartbeat.md) | 기기 → 서버 보조 하트비트 (`last_seen`만 갱신) | 대기 | ADR-0003 | 2026-09-30 |
| [0005](0005-connection-token-in-hash.md) | 연결 토큰을 해시에 저장해 같은 서버 재연결을 저장소 수준에서 구분 | 대기 | ADR-0004 | 2026-09-30 |
| [0006](0006-reconnect-jitter.md) | 재연결 지연 지터 | 대기 | PRD 한계 | 2026-09-30 |
| [0007](0007-command-ack.md) | 명령 전달 확인(ack) | 대기 | ADR-0005 | 2026-09-30 |

형식:

```
# NNNN. 제목
상태 / 날짜 / 출처
## 문제        무엇이 어긋나거나 부족한가
## 제안        무엇을 하면 되나
## 채택 조건   언제 하기로 할 것인가 (이 조건이 오기 전에는 하지 않는다)
## 결정 기록   상태가 바뀔 때 한 줄씩 추가
```
